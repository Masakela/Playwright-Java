# QA Automation KPIs

The CI pipeline publishes a **stakeholder dashboard** of test KPIs on every run.
It is generated by `scripts/kpi-report.js` from the raw results of both suites
(Java/TestNG JUnit XML + Playwright JSON) and deployed to GitHub Pages alongside
the full Allure and Playwright HTML reports.

## What each KPI means

| KPI | Definition | Why stakeholders care |
|-----|------------|-----------------------|
| **Pass rate** | passed / (passed + failed), skipped excluded | headline quality signal for the release |
| **Total / Executed** | all tests / those that actually ran | coverage and how much was skipped |
| **Failed** | tests that did not meet their assertion | open quality risk |
| **Skipped** | tests not run (e.g. no live endpoint) | gaps in what was verified |
| **Flaky** | passed only after a retry | reliability / trust in the suite |
| **Duration** | total wall-clock test time | pipeline cost and feedback speed |
| **By suite** | UI Regression, Agent Workflows (Java), TS per browser | where risk is concentrated |

## Agent quality gates (AI-as-system-under-test)

Because the agent is the system under test, four gates are tracked specifically:

- **Eval harness (task-success)** - the golden eval set meets the success threshold.
- **Guardrails (refusals)** - out-of-scope / unsafe requests are refused.
- **Non-determinism (invariants)** - properties hold across repeated runs.
- **Data validation** - the records the agent produces are complete and correct.

## Where to find it

- **Dashboard:** the GitHub Pages site root (`index.html`).
- **Allure report:** `/allure/` on the same site.
- **Playwright HTML report:** `/playwright-report/` on the same site.
- **Raw data:** `kpi-summary.json` (machine-readable) and `kpi-summary.md`
  (also posted to the Actions run summary and available as a build artifact).

## Run it locally

```bash
# after running the suites (so target/surefire-reports and
# playwright-ts/test-results/results.json exist):
node scripts/kpi-report.js \
  --junit target/surefire-reports \
  --pw playwright-ts/test-results/results.json \
  --out kpis-out
# open kpis-out/index.html
```
